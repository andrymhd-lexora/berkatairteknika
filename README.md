# PT Berkat Air Teknika — Solusi Air dan Teknologi

Situs web resmi dan platform rekayasa digital **PT Berkat Air Teknika**, penyedia solusi terdepan di Indonesia untuk instalasi pengolahan air bersih (WTP), air limbah industri (IPAL), sistem klorinasi gas presisi tinggi, pengendalian emisi udara (Wet Scrubber), inovasi pabrik garam, dan penerapan ekonomi sirkular.

---

## 🌟 Fitur Utama & Ruang Lingkup Sistem

### 1. Identitas Bisnis & 4 Pilar Utama
- **Solusi Pengolahan Limbah & Lingkungan**: Rancang bangun EPC, revamping, dan optimasi biologi IPAL (MBBR & Anaerobic).
- **Inovasi Produk Pengolahan Garam Berkualitas Tinggi**: Sistem kristalisasi, pencucian, dan pemurnian garam industri kadar NaCl >99.2%.
- **Penerapan Ekonomi Sirkular**: Biokonversi lumpur biologis IPAL (non-B3) menjadi pupuk kompos organik bernilai komersial tinggi.
- **Penerapan Inovasi Teknologi Berkelanjutan**: Integrasi sensor IoT dan telemetri SPARING KLHK real-time untuk efisiensi energi dan pemantauan kualitas lingkungan kontinu.

### 2. Katalog Peralatan & Sistem Rekayasa
- **MBBR (Moving Bed Biofilm Reactor)**: Virgin HDPE media K1, K3, K5 dengan luas permukaan terproteksi hingga 1200 m²/m³.
- **Tabung Klorin (Chlorine Ton Container 1000 kg & 50 kg)**: Standar fabrikasi ASME Section VIII & DOT-3AA480 dilengkapi sertifikat uji hidrostatik.
- **Fan Blower (Roots Blower & Turbo Aeration)**: Pasokan aerasi kontinu efisiensi tinggi dengan getaran ultra rendah.
- **Pompa Sirkulasi (Magnetic Drive & Heavy-Duty Sludge)**: Tahan korosi bahan kimia asam/basa pekat dan lumpur abrasif.
- **Sistem Klorinasi Gas (All-Vacuum)**: Vacuum regulator bersertifikasi *The Chlorine Institute (USA)*, chlorinator presisi, dan hydraulic ejector.
- **Sistem Wet Scrubber**: FRP / PP Packed Bed Scrubber untuk netralisasi gas beracun ($Cl_2$, $HCl$, $SO_2$, $H_2S$) dengan efisiensi >99.8%.

### 3. Kalkulator Rekayasa Air Interaktif (Engineering Sizing & Estimator Engine)
- **Simulasi IPAL & MBBR**: Perhitungan debit influent, beban BOD/COD harian, volume media MBBR ($m^3$), dimensi tangki aerasi, dan pasokan udara blower ($m^3/min$).
- **Kalkulasi Klorinasi Gas**: Konversi debit WTP dan dosis PPM ke kebutuhan gas harian ($kg Cl_2/hari$), PPD, serta rekomendasi konfigurasi tabung klorin.
- **Sizing Wet Scrubber & Fan Blower**: Estimasi diameter menara ($mm$), tinggi packing bed ($m$), dan daya motor fan blower ($kW$).
- **Model Ekonomi Sirkular**: Estimasi tonase pupuk kompos granul per bulan, proyeksi nilai ekonomi baru (Rp/bulan), dan reduksi emisi $Ton CO_2eq$/tahun.
- **Direct RFQ Transfer**: Mentransfer hasil perhitungan kalkulator langsung ke formulir RFQ dalam satu klik.

### 4. Fitur Interaktif & Pengalaman Pengguna
- **Bilingual Support (ID/EN)**: Beralih instan antara Bahasa Indonesia dan Bahasa Inggris pada seluruh konten teknis.
- **Dark & Light Mode Luxury Theme**: Visual modern geometric dengan palet biru safir, indigo, dan cyan tech glow.
- **Portfolio & Case Studies**: Studi kasus nyata pada PDAM, pabrik makanan & minuman, pabrik kimia, dan industri agro dengan data perbandingan *Before vs. After*.
- **Knowledge Base & Blog**: Artikel teknis perbandingan teknologi pengolahan air dan regulasi lingkungan (Baku Mutu KLHK).
- **Interactive Live Chat Widget**: Asisten teknis virtual dengan simulasi rekomendasi rekayasa proses instan.
- **Multi-Step RFQ & Emergency Response**: Formulir tender & penawaran harga dengan unggah berkas spesifikasi teknis dan hotline tanggap darurat 24 jam.

## 🛠️ Tech Stack & Dependensi

- **Frontend Core**: React 19, TypeScript
- **Styling**: Tailwind CSS v4, Custom CSS Design Tokens

- **Animations & Micro-interactions**: Smooth transitions, canvas-confetti, dynamic modal popups

## 🚀 Panduan Menjalankan Aplikasi

```bash
# 1. Pastikan dependensi terpasang
npm install

# 2. Jalankan development server
npm run dev

# 3. Jalankan typecheck & linting
npm run lint

# 4. Build produksi
npm run build
```
